// Conjunto de deudas (creditos de un cliente o de toda la financiera). No se persiste.

M12. Decorator: cargos sobre la cuota expansión del dominio

Commits 4eab370, 54cd991; 3fc5b9d lo muda a CondicionesDeCredito. Tabla nueva credito_cargos.

Patrón
Decorator (GoF, estructural): agrega responsabilidades a un objeto por composición, en vez de una subclase por combinación.
Problema (código antes)

Un préstamo real suma cargos opcionales (seguro de vida, gastos). Con herencia: una subclase por plan × combinación.

backend/src/main/java/com/uade/tpejemplo/model/Credito.java · V3 (tag v3)

        return tipoPlan.calculo();
    }
Solución (código después)

Cada cargo envuelve el cálculo y suma lo suyo; CondicionesDeCredito arma la pila (M17). Cada capa agrega su renglón: el desglose recorre la misma pila; la ficha lo muestra.

JPA guarda el plan por nombre (tipo_plan); TipoPlan es el selector persistible y el Contexto (CondicionesDeCredito) obtiene la estrategia en calculo(); mismo criterio que TipoCargo.

    private CalculoDeCuota calculo() {

    }

// Cargo que se suma a la cuota sin tocar el sistema de amortizacion.
// Decorator: envuelve un CalculoDeCuota, delega en el y le suma su cargo
public abstract class CargoSobreCuota implements CalculoDeCuota {

    private final CalculoDeCuota envuelto;

    protected CargoSobreCuota(CalculoDeCuota envuelto) {
        this.envuelto = envuelto;
    }

    @Override
    public BigDecimal importeCuota(BigDecimal capital, BigDecimal tasaInteres, int cantidadCuotas) {
        return envuelto.importeCuota(capital, tasaInteres, cantidadCuotas).add(cargo(capital, cantidadCuotas));
    }

    // Cada capa agrega su renglon sobre el desglose del envuelto
    @Override
    public List<Renglon> desglose(BigDecimal capital, BigDecimal tasaInteres, int cantidadCuotas) {
        List<Renglon> desglose = new ArrayList<>(envuelto.desglose(capital, tasaInteres, cantidadCuotas));
        desglose.add(new Renglon(nombre(), cargo(capital, cantidadCuotas)));
        return desglose;
    }

    protected abstract String nombre();

    protected abstract BigDecimal cargo(BigDecimal capital, int cantidadCuotas);
}

Pregunta trampa: “¿No es otra Strategy?”
No: Strategy elige un algoritmo; los decoradores se apilan sobre él.
Pregunta trampa: “¿Por qué no se guarda el desglose?”
El importe guardado en la cuota es el hecho; el desglose se recalcula desde las condiciones para explicarlo.
Pregunta trampa: “¿Para qué está TipoCargo?”
Un decorador no se guarda ni viaja en el JSON: se guarda el nombre del cargo (credito_cargos) y con él se rearma la pila. Cada constante sobrescribe aplicarSobre con su decorador: Polymorphism en vez de un switch por tipo.

    // Sin token: lo usa el ADMIN para dar de alta a otro, no para entrar.
    @Transactional
    @Override
    public UsuarioResponse registrarConRol(RegisterRequest request, Rol rol) {
        if (rol == Rol.ADMIN) {
            throw new BusinessException("No se puede dar de alta un administrador");
        }
        return UsuarioResponse.desde(crear(request, rol));
    }

    private Usuario crear(RegisterRequest request, Rol rol) {
        if (usuarioRepository.existsByUsername(request.getUsername())) {
            throw new BusinessException("El usuario '" + request.getUsername() + "' ya existe");
        }

        Usuario usuario = Usuario.nuevo(
            request.getUsername(),
            passwordEncoder.encode(request.getPassword()),
            rol,
            Permisos.ninguno()
        );

        return usuarioRepository.save(usuario);
    }

        BigDecimal coeficiente = BigDecimal.ONE.add(tasaInteres.divide(CIEN, 4, RoundingMode.HALF_UP));

backend/src/main/java/com/uade/tpejemplo/model/plan/InteresSimple.java · V4 (iteracion4)

    private BigDecimal totalADevolver(BigDecimal capital, BigDecimal tasaInteres, int cantidadCuotas) {
        BigDecimal interes = tasaInteres.divide(CIEN, 4, RoundingMode.HALF_UP).multiply(BigDecimal.valueOf(cantidadCuotas));
        return capital.multiply(BigDecimal.ONE.add(interes)).setScale(2, RoundingMode.HALF_UP);
    }
