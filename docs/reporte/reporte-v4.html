// Conjunto de deudas (creditos de un cliente o de toda la financiera). No se persiste.
// Composite: suma la deuda de sus hijos sin saber si son creditos o cuotas
public final class Cartera implements Deuda {

    private final List<Deuda> deudas;

    private Cartera(List<Deuda> deudas) {
        this.deudas = deudas;
    }

    public static Cartera de(List<? extends Deuda> deudas) {
        return new Cartera(List.copyOf(deudas));
    }

    public BigDecimal saldo() {
        return sumar(Deuda::saldo);
    }

    public BigDecimal montoVencido() {
        return sumar(Deuda::montoVencido);
    }

    private BigDecimal sumar(Function<Deuda, BigDecimal> monto) {
        return deudas.stream()
            .map(monto)
            .reduce(BigDecimal.ZERO, BigDecimal::add);
    }
}

M12. Decorator: cargos sobre la cuota expansión del dominio

Commits 4eab370, 54cd991. Tabla nueva credito_cargos.

Patrón
Decorator (GoF, estructural): agrega responsabilidades a un objeto sin herencia.
Problema (código antes)

Un préstamo real suma cargos opcionales (seguro de vida, gastos). Con herencia: una subclase por plan × combinación.

backend/src/main/java/com/uade/tpejemplo/model/Credito.java · V3 (tag v3)
    // Strategy: el contexto delega el cálculo de la cuota en la estrategia elegida al otorgar (no cambia después)

    }
Solución (código después)

Cada cargo envuelve el cálculo y suma lo suyo; Credito arma la pila.

backend/src/main/java/com/uade/tpejemplo/model/Credito.java · V4 (iteracion4)
    // Strategy: el contexto delega el cálculo de la cuota en la estrategia elegida al otorgar (no cambia después)
    // Decorator: cada cargo del credito envuelve a la estrategia y le suma lo suyo
    private CalculoDeCuota calculo() {
        CalculoDeCuota calculo = tipoPlan.calculo();
        for (TipoCargo cargo : cargos) {
            calculo = cargo.aplicarSobre(calculo);
        }
        return calculo;
    }
backend/src/main/java/com/uade/tpejemplo/model/plan/CargoSobreCuota.java · V4 (iteracion4)
// Cargo que se suma a la cuota sin tocar el sistema de amortizacion.
// Decorator: envuelve un CalculoDeCuota, delega en el y le suma su cargo
public abstract class CargoSobreCuota implements CalculoDeCuota {

    private final CalculoDeCuota envuelto;

    protected CargoSobreCuota(CalculoDeCuota envuelto) {
        this.envuelto = envuelto;
    }

    @Override
    public BigDecimal importeCuota(BigDecimal capital, BigDecimal tasaInteres, int cantidadCuotas) {
        return envuelto.importeCuota(capital, tasaInteres, cantidadCuotas).add(cargo(capital, cantidadCuotas));
    }

    protected abstract BigDecimal cargo(BigDecimal capital, int cantidadCuotas);
}

backend/src/main/java/com/uade/tpejemplo/model/TipoCargo.java · V4 (iteracion4)
// Cargos opcionales que se eligen al otorgar un credito.
// Decorator: cada cargo envuelve el calculo con su decorador concreto
public enum TipoCargo {
    SEGURO_DE_VIDA(SeguroDeVida::new),
    GASTO_DE_ADMINISTRACION(GastoDeAdministracion::new);

    private final UnaryOperator<CalculoDeCuota> decorador;

    TipoCargo(UnaryOperator<CalculoDeCuota> decorador) {
        this.decorador = decorador;
    }

    public CalculoDeCuota aplicarSobre(CalculoDeCuota calculo) {
        return decorador.apply(calculo);
    }
}
